# Technical reference

The [conveyor reference](object-sorting-conveyor.pdf) describes an ESP32-CAM/Uno design with a stepper-driven belt and servo gate. Its intended color labels and camera-to-controller integration are not fully implemented in the recovered code.

Read [implementation status](../architecture.md) before using the reference as build instructions. Its licensing suggestions and performance claims do not change this repository's license or establish tested behavior.

Private administrative and financial materials are excluded from the public repository.
